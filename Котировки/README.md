# Построение свечного графика — 20 вариантов

**ВНИМАНИЕ: комбинированный учебный ряд, не фактические внутридневные торги.**

20 валют × 3 даты × 20 записей = 1200 значений. Для каждой даты фактический официальный курс Банка России использован как **опорное последнее значение** таблицы на 19:30. Остальные 19 значений смоделированы. Само время 19:30 является **условным учебным временем**, а официальная ставка ЦБ **не является биржевой ценой закрытия в 19:30**. Первое наблюдение в 10:00 тоже смоделировано. Поэтому формально построенные свечи являются **учебными свечами по 20 наблюдениям**, а не историческими свечами рынка.

Реальные официальные курсы на 28, 29 и 30 октября 2026 года приведены по источнику, перепубликующему Банк России:
- https://kurs-rublya.ru/kursy-valyut-na-28-10-2026/
- https://kurs-rublya.ru/kursy-valyut-na-29-10-2026/
- https://kurs-rublya.ru/kursy-valyut-na-30-10-2026/

Официальный сайт: https://www.cbr.ru/currency_base/daily/

## Задание
Для каждого дня: Open — первая строка (10:00); Close — последняя (19:30); High — максимум 20 строк; Low — минимум 20 строк. Рассчитать абсолютный и процентный размах (High−Low и (High−Low)/Open × 100%), изменение Close−Open; построить три свечи; определить направление каждого дня; сделать вывод. Не использовать значения High/Low из сторонних исторических таблиц: требуется анализировать предложенные 20 наблюдений.
